Privacy notice

Effective 30 September 2026.

Toby Private Backup is operated by its owner for personal backup and recovery. It is not offered to other users.

Google data accessed

The desktop application uses Google Drive's drive.file permission to create and access its own backup objects, or files explicitly selected by the owner. It checks the authorized account email and storage quota to ensure the intended private destination is used.

Purpose and storage

Selected files are encrypted locally with restic before rclone uploads them to Google Drive. The desktop application downloads encrypted copies for recovery checks. Google receives encrypted backup objects; the recovery password is not uploaded with the repository. OAuth credentials and refresh tokens are protected locally using Windows user-level encryption. The recovery password is separately held in the owner's password manager.

Sharing and retention

The operator does not sell Google user data or use it for advertising. Backup contents are not published through this website or GitHub. Google Drive stores the encrypted objects for the owner's use; local recovery copies are retained for verification. Source files and historical backups are not automatically deleted by this pilot. The owner controls later retention and deletion decisions.

Owner controls

The owner can revoke this application's access through Google Account permissions. Revoking access stops future access but does not automatically delete existing backup objects. Existing backups may be managed through the owner's Google Drive account.

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
