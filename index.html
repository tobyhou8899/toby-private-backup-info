Toby Private Backup

A personal desktop backup connection for its owner's Windows computer. It uses rclone to transfer restic-encrypted backup archives to the owner's Google Drive.

This is a private, owner-operated tool, not a public backup service. Google authorization uses the drive.file scope, limited to files created by the application or explicitly selected for it. Backups are encrypted locally before upload. Recovery passwords are kept separately in the owner's password manager.

This website contains information only. It does not accept passwords, OAuth tokens, backup files, or payments.
